# Einhorn-Herde

Verbindliche Designquelle: [Issue #60](https://github.com/Levtos/control/issues/60).
Alle neun Originalfiguren (1024×1536) und neun Originalicons (1254×1254) stammen
aus Bennis freigegebener ZIP mit bereinigten transparenten Icon-Ecken.
PNGs werden bytegleich archiviert; sources.json enthält ihre SHA-256-Werte.
Originale niemals überschreiben. Der Steckbrief ersetzt nur die beauftragte
SVG-Checklisten-Zeile durch die PNG-/Petrol-/Eckenregel.

Wuschel und Traber verwenden reproduzierbare Ableitungen aus einem gepinnten
Commit dieser Quelle. Weitere Module sind hier ausschließlich Vorlagen.
Icons: Kachel/Store/Favicon/eigene Navigation. Figuren: Kopf/Leerzustand/
Einrichtung/Fehler. Mähnenfarben sind Identität, getrennt von Statusfarben.
